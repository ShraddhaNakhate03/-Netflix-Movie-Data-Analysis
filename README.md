# 🎬 Netflix Movie Data Analysis

This project performs **Exploratory Data Analysis (EDA)** on a Netflix movie dataset to discover insights about movie trends, popularity, genres, and release patterns.

Using **Python and data analysis libraries**, this project analyzes a dataset of thousands of movies to answer important business questions such as the most popular genres, highest rated movies, and yearly movie release trends.

---

## 📊 Project Objectives

The main goal of this project is to analyze movie data and answer key analytical questions:

- What is the **most frequent movie genre on Netflix?**
- Which movie has the **highest vote average?**
- Which movie has the **highest popularity score?**
- Which movie has the **lowest popularity score?**
- Which **year had the highest number of movie releases?**

These insights help understand **content trends and audience preferences**.
